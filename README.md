# Task Management Backend

Backend API for a Task Management System built with Node.js, Express.js and PostgreSQL.

## Technologies

- Node.js
- Express.js
- PostgreSQL
- JWT Authentication
- bcryptjs
- Express Validator

## Main Features

- User registration and login
- JWT authentication
- Role-based authorization
- User management
- Task management
- Task assignments
- Task progress tracking
- Task reviews
- Task submissions
- Performance reports
- Input validation

## API Routes

- `/api/auth`
- `/api/users`
- `/api/tasks`
- `/api/task-assignments`
- `/api/task-progress`
- `/api/task-reviews`
- `/api/task-submissions`
- `/api/performance-reports`
